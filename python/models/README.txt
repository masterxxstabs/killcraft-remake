Downloaded 3D gun models go here, one folder per weapon id:
    models/pistol/model.glb
    models/rifle/scene.gltf (+ scene.bin, textures/)

The easiest way to fill this folder is:
    python tools/sketchfab_guns.py

You can also drop in your own .glb / .gltf / .obj / .bam files by hand.
If a model points the wrong way in game, hold it and press F8 (turn) or F9 (roll).
CREDITS.md lists the authors - keep it if you share the game (CC-BY requires it).
