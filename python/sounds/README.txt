Put your own sound effects here to replace the built-in ones.

Name the file after the effect, as .wav or .ogg. For example:

Guns:
  shoot_pistol.wav  shoot_heavy_pistol.wav  shoot_smg.wav  shoot_rifle.wav
  shoot_battle_rifle.wav  shoot_shotgun.wav  shoot_scatter.wav  shoot_sniper.wav
  shoot_suppressed.wav  shoot_nailgun.wav  shoot_railspike.wav  shoot_firework.wav
  reload_out.wav  reload_in.wav  reload_rack.wav  pump.wav  equip.wav
  casing.wav  empty.wav  reload.wav

Movement:
  step.wav  land.wav  slide.wav  mantle.wav

Everything else:
  swing.wav  hit.wav  headshot.wav  thud.wav  hurt.wav  coin.wav  heal.wav
  buy.wav  deny.wav  groan.wav  spit.wav  boom.wav  powerup.wav  blink.wav
  death.wav  wave_start.wav  wave_clear.wav  boss_roar.wav  game_over.wav

Which gun uses which sound is the "sound" field in blockhold/data/weapons.py.
Restart the game after adding files.
