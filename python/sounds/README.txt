Put your own sound effects here to replace the built-in ones.

Name the file after the effect, as .wav or .ogg. For example:
  shoot_pistol.wav   shoot_nailgun.wav   shoot_scatter.wav   shoot_railspike.wav
  shoot_firework.wav swing.wav  hit.wav  headshot.wav  thud.wav  reload.wav
  empty.wav  hurt.wav  coin.wav  heal.wav  buy.wav  deny.wav  groan.wav  spit.wav
  boom.wav  powerup.wav  blink.wav  death.wav  wave_start.wav  wave_clear.wav
  boss_roar.wav  game_over.wav

Restart the game after adding files.
